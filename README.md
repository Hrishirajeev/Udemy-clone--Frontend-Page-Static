# Udemy Clone

A responsive front-end clone of the Udemy website built using only **HTML** and **CSS**. This project recreates the look and feel of Udemy's homepage with a clean, modern, and responsive design.

## 🚀 Features

- Responsive layout
- Modern and clean UI
- Navigation bar
- Hero section
- Course categories
- Featured courses section
- Footer
- Mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```
Udemy-Clone/
│── index.html
│── udemystyle.css
│── images/
```

## ▶️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Udemy-Clone.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

## 🎯 Purpose

This project was created to practice front-end web development by recreating the UI of the Udemy homepage using only HTML and CSS.
